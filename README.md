# Replier tout

Ajoute dans la barre latérale d’Obsidian un bouton qui replie tous les titres et les listes de la note Markdown active.

## Installation avec BRAT

1. Installer BRAT dans le vault
2. Dans les réglages de BRAT, choisir **Ajouter une extension bêta**
3. Coller l’adresse du dépôt GitHub de ce module
4. Activer **Replier tout** dans les extensions communautaires

Le module ne nécessite ni réglage ni raccourci clavier.
